# Chrome Video Subtitle Player

A simple browser-based HTML5 video player that allows you to play local video files with SRT or WebVTT subtitles directly in Google Chrome.

## ✨ Features

- 🎬 Play local MP4 and other browser-supported video files
- 💬 Support SRT subtitle files
- 📄 Support WebVTT subtitle files
- 🔄 Automatically converts SRT subtitles to WebVTT
- 🌐 Runs directly in Google Chrome
- 🔒 No server or video upload required
- ⚡ Lightweight and easy to use

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Chrome_Player_Video_Subtitle.html` in Google Chrome.
3. Select your video file.
4. Select your `.srt` or `.vtt` subtitle file.
5. Play the video.
6. Enable subtitles from the video player's subtitle menu if necessary.
